# MDAAI cover artwork

The current documentation cover depicts an AI-generated coiled mythical guardian, created using the original MDAAI guardian emblem as a project reference. The creature image is generated artwork in an engraved visual style, not a historical engraving or work attributed to a historical artist.

The approved cover layout and E.M.K. credit are retained. Cover layout and adaptation are by E.M.K.; the original MDAAI emblems are original project artwork. Owner-authorized new project artwork is supplied under Apache-2.0, without relicensing inherited publication content or third-party material.

The current cover does not contain the historical boa illustration used in an earlier unpublished draft. That draft’s historical source attribution does not apply to this generated creature.
